Entry for the make.fun bounty "Tell a Whole Story in 32 Characters":
one Wi-Fi network name of at most 32 characters that lands a joke and
implies a whole story.

Run: `python3 main.py` — writes the name to `/output/entry.txt`
(Python stdlib only, no network, deterministic).
